## What we do

DataGateLodge builds custom AI agents on governed infrastructure.
Not a consultancy bolting guardrails onto someone else's stack — every
agent we deploy runs through Gatelodge, our own self-hosted AI gateway,
with model routing, budget caps, audit trails, and escalation paths
built into the architecture.

## The types of agents we build

- **Helpdesk agents** — answer questions, route tickets, escalate to
  humans when uncertain (the Gatekeeper on this site is a live example)
- **Research assistants** — gather information, synthesize findings,
  cite sources
- **Workflow automation** — read inputs, make decisions, trigger actions,
  with human sign-off at critical gates
- **Document processors** — classify, extract, route, and audit
  document flows
- **Monitoring agents** — watch systems, alert on anomalies, report
  on budget usage

## The Gatehouse Method — five steps

**1. Survey the Estate**
We document existing workflows end-to-end: every person, system,
document, and handoff. Not the org-chart version — what actually
happens on a Tuesday. Deliverable: annotated process map with
friction points scored by frequency, cost, and agent-replaceability.

**2. Map the Gates**
We identify every decision point where a human currently judges,
approves, routes, or escalates. For each: what information feeds the
decision, what happens on each branch, and the cost of error.
Deliverable: decision-point inventory with agent-readiness scoring.

**3. Design the Pass**
We re-engineer the workflow: which gates become agentic loops,
which stay human, and how the two hand off cleanly. We design the
agent's knowledge base, confidence thresholds, escalation paths,
model routing plan, and audit specification.
Deliverable: re-engineered process with agent architecture.

**4. Post the Keeper**
We build and deploy the agent on Gatelodge enterprise infrastructure:
model routing with budget caps, tamper-evident audit chain, allowlisted
backends, confidence scoring with escalation, and a live knowledge base.
Deliverable: production agent on your infrastructure.

**5. Walk the Wall**
We stay. We monitor confidence rates, escalation patterns, cost per
decision, and knowledge gaps. The agent improves with real-world use.
Deliverable: operations reports with recommendations and KB updates.

## Why this is different

Most AI consultancies build agents on top of raw API access —
OpenAI, Anthropic, etc. — with governance bolted on. We build on
our own product, which means:

- Budgets are enforced by hard stops at the infrastructure level
- Every exchange is hash-linked and tamper-evident
- Model routing optimizes cost without sacrificing quality
- Unapproved models can't even be requested
- All of it runs on your infrastructure, not ours

The Gatekeeper answering questions on this site right now is our
proof: built with this method, running on this infrastructure.
